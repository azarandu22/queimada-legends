QUEIMADA LEGENDS - PROTOTIPO 0.1

COMO ABRIR:
1. Extraia a pasta.
2. Abra a pasta "queimada-legends" no VS Code.
3. Abra o arquivo index.html no navegador.
4. Clique em JOGAR.

ESTRUTURA:
index.html -> telas e elementos do jogo
css/style.css -> visual
js/game.js -> lógica, movimento, bola, IA e poderes
data/characters.js -> personagens
images/ -> futuras imagens
sounds/ -> futuros sons

CONTROLES NO PC:
WASD ou setas = mover
Espaço = arremessar
D = defender
E = poder

NO CELULAR:
Use os botões na parte inferior da arena.
